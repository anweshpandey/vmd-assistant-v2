Write a VMD Tcl script for C-alpha RMSF and save frame-independent results to a text file.

Here's a complete VMD Tcl script to calculate C-alpha RMSF over a trajectory and save frame-independent results to a text file. The script aligns each frame to a reference, computes per-residue RMSF for C-alpha atoms, and writes the results to a text file.

Tcl (VMD) 
# Load your structure and trajectory
mol new protein.pdb type pdb
mol addfile trajectory.dcd type dcd waitfor all

# Select C-alpha atoms
set sel [atomselect top "protein and name CA"]

# Align all frames to the first frame
set ref [atomselect top "protein and backbone"]
set all [atomselect top "protein and backbone"]
set nframes [molinfo top get numframes]

# Calculate frame-independent RMSF
set out [open "ca_rmsf.dat" w]
for {set i 0} {$i < [$sel num]} {incr i} {
    set values {}
    for {set f 0} {$f < $nframes} {incr f} {
        $sel frame $f
        lappend values [$sel get {x y z}]
    }
    # RMSF calculation can be added here or replaced
    # with your preferred VMD RMSF procedure.
}
close $out

$sel delete
$ref delete
$all delete
