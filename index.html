VMD Assistant AI v2.5

A focused scientific assistant for Visual Molecular Dynamics. The frontend is static and safe for GitHub Pages; AI credentials belong only in the server-side gateway.

Free AI routing

OpenRouter free models, DeepSeek free variants, Gemini free, and Groq free can be selected or used through automatic fallback. Free endpoints are rate-limited and their availability can change.

Premium later

OpenAI/GPT, Anthropic/Claude, paid DeepSeek and paid Gemini are intentionally shown as coming later. A ChatGPT subscription is not an API key.

Security model

  • No API key is requested from visitors.
  • No API key is stored in localStorage.
  • GitHub Pages contains only public frontend code.
  • Provider keys are Cloudflare Worker secrets.
  • Free mode rejects paid provider/model requests.
